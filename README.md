# 📚 Online Exam System

یک سیستم کامل برای برگزاری آزمون‌های آنلاین با مدیریت معلم، دانش‌آموز و ادمین.

## ✨ قابلیت‌ها

- 🔐 **سیستم ورود** با نقش‌های مختلف (مدیر، معلم، دانش‌آموز)
- 👑 **پنل مدیریت** برای تنظیمات کلی سایت
- 👨‍🏫 **پنل معلم**:
  - افزودن/ویرایش/حذف سوالات
  - تنظیم زمان و تاریخ آزمون
  - مدیریت دانش‌آموزان
  - مشاهده گزارش‌ها
- 👨‍🎓 **پنل دانش‌آموز**:
  - شرکت در آزمون‌های زمان‌دار
  - مشاهده نمرات و جزئیات
- 🖼️ **آپلود تصویر** برای سوالات
- 📄 **خروجی PDF** از نتایج آزمون
- 📱 **طراحی واکنش‌گرا** (Responsive)

## 🛠️ تکنولوژی‌ها

- PHP 7.4+
- MySQL
- HTML5, CSS3, JavaScript
- AJAX

## 🚀 نصب و راه‌اندازی

1. پروژه را در پوشه‌ی `htdocs` کپی کنید
2. پایگاه داده را ایجاد کنید
3. فایل `config.php` را ویرایش کنید
4. فایل `clean_database.php` را اجرا کنید
